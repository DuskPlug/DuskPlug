Getting started with DuskPlug

DuskPlug controls Tuya-compatible smart plugs from the system tray (Windows and Linux) or menu bar (macOS). This page summarizes the setup; the full guide with screenshots is on GitHub.

1. Install DuskPlug

Windows (recommended):

winget install DuskPlug.DuskPlug

Or download the MSI or portable ZIP from GitHub Releases.

Linux: download DuskPlug-Linux-x64.tar.gz, extract it, and run ./duskplug.

macOS: download DuskPlug-macOS.zip, unzip DuskPlug.app, and open it (right-click → Open the first time if macOS blocks an unsigned build).

2. Create a Tuya cloud project

  1. Sign up at iot.tuya.com (Tuya Developer Platform).
  2. Create a Smart Home cloud project in the data center that matches your phone app region.
  3. Authorize IoT Core and Smart Home Basic Service.
  4. Copy Access ID and Access Secret from the project Overview.
  5. Link your Smart Life / Tuya phone app account under Devices → Link Tuya App Account.
  6. Copy the Device ID for each plug from All Devices.

3. Configure DuskPlug

First run opens Settings. Enter your credentials and Device ID, then choose Smart Mode or Schedule Mode.

For Smart Mode, allow location access when prompted (on Windows, enable desktop apps in Location privacy settings), then click Detect Location.

Full walkthrough: docs/GETTING-STARTED.md on GitHub
