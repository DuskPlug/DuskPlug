# Screenshots

## Tray (manual — do not regenerate)

`tray-menu.png` is a **real Windows capture**, not a mockup.

- **Source:** `source/tray-menu.png` — replace this file when updating the tray screenshot.
- **Export:** run `python scripts/update_tray_screenshots.py` to copy source → `tray-menu.png`.

Do not overwrite these from `scripts/capture_readme_screenshots.py`, `make_tray_menu_mockup.py`, or similar.

## Settings tabs (manual captures)

Each settings tab has its own screenshot:

| File | Tab |
|------|-----|
| `settings-connection.png` | Connection |
| `settings-devices.png` | Devices |
| `settings-location.png` | Location |
| `settings-screen.png` | Screen |
| `settings-general.png` | General |

`settings-dialog.png` is a copy of `settings-connection.png` for backwards compatibility.

- **Sources:** `source/settings-*.png`
- **Capture:** with DuskPlug installed, run:

  ```powershell
  python scripts/capture_settings_screenshot.py
  ```

  This injects the app logo into `assets/settings.html` for each capture, then restores the file.

## App icons (generated)

`icon-app-*.png` files are generated by `scripts/generate_icons.py`.
